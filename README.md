## 🎯 What I Built

- Cleaned and analyzed a **5,000-record marketing campaign dataset** using Python & Pandas
- Built a **SQLite database** for structured analysis
- Performed marketing performance analysis using **SQL**
- Created interactive Power BI dashboards for **campaigns, channels, customers & locations**
- Developed **DAX measures** for Spend, Revenue, CTR, Conversion Rate, CPA, ROAS and ROI
- Built an interactive **3-page Power BI dashboard**
- Added dynamic filters for **Date, Channel, Campaign, Location, Age Group and Customer Type**
- Analyzed the complete marketing funnel from **Impressions → Clicks → Leads → Conversions**

## 📈 Key Insights

- **11.72 ROAS** across the marketing dataset
- **Google Ads** generated the highest revenue among channels
- **Facebook** accounted for the highest marketing spend
- **Diwali Campaign** generated the highest number of conversions
- **New Year Offer** recorded the lowest conversions
- Marketing performance varied across channels, campaigns, and customer segments
